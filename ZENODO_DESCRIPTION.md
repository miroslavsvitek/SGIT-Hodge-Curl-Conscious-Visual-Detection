# Zenodo record description

This archive accompanies manuscript v0.6, **“Reproducible Hodge-Curl Relational Geometry of Conscious Visual Detection”**, by Miroslav Svítek.

It contains the manuscript source and compiled PDF, exact frozen discovery and replication analysis scripts/configurations, and supplementary numerical objects defining the discovery-derived Hodge geometry transferred unchanged to replication.

The study tests an empirical core of Spatiotemporal Geometric Information Theory (SGIT). Chronology-sensitive pairwise EEG relations are represented as antisymmetric edge flows and decomposed with Hodge theory. The primary observable is the temporal trajectory of normalized Hodge-curl modal energy. Primary inference uses within-subject label permutations with complete recomputation of all leave-one-subject-out templates on every draw.

The curl statistic exceeded its empirical permutation null in the exploratory discovery dataset (N=30, p=0.0004) and in an independently frozen matched replication dataset (N=35, p=0.0064). Matched Hodge-gradient analyses were unsupported. Absolute cosine-difference scores are small; standardized LOSO effect sizes are descriptive because LOSO templates overlap across held-out subjects.

No participant EEG data are redistributed. Original public datasets are available at:
- https://doi.org/10.17045/STHLMUNI.26879077
- https://doi.org/10.17045/STHLMUNI.5418967
